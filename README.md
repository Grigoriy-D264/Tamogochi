# Тамагочи-кликер

Консольная игра по учебному заданию Яндекс Практикума. Логика разделена на
питомца, кликер и игру; реализации наследуются от абстрактных классов шаблона.

## Запуск

Нужен Python 3.10 или новее. Команды выполняются из папки с `main.py`:

```bash
python main.py
```

Сама игра использует только стандартную библиотеку Python, установка пакетов
для запуска не нужна.

## Управление

| Команда | Действие |
| --- | --- |
| 1 | Работа: заработать 10–20 монет |
| 2 | Купить еду |
| 3 | Купить лекарство |
| 4 | Выбрать еду из сумки и покормить питомца |
| 5 | Выбрать лекарство из сумки и лечить питомца |
| 6 | Поиграть с питомцем |
| 7 | Отдохнуть |
| 0 | Выйти |

В списке предметов вводите номер; `0` отменяет выбор. Неверный ввод, отмена,
пустая сумка и нехватка денег не расходуют ход. Ctrl+C или конец ввода завершают
игру корректно. Состояние между запусками не сохраняется.

## Правила

Питомец начинает со здоровьем и энергией 100, голодом и усталостью 0.
Начальный баланс — 0 монет. Каждый успешный ход увеличивает голод и усталость
на 5 и уменьшает энергию на 5. Если голод или усталость достигают 80, здоровье
уменьшается на 10 за ход; одновременно высокие показатели не удваивают урон.

Еда снижает голод на указанное насыщение и расходуется. Игра расходует ещё
10 энергии и увеличивает усталость на 10. Отдых добавляет 30 энергии и снимает
30 усталости; при болезни эти значения равны 15. Голод, усталость и энергия
всегда находятся в диапазоне 0–100, здоровье не превышает 100.

Здоровый питомец может заболеть на каждом ходе с вероятностью 10%. Болезнь
дополнительно отнимает 5 здоровья и добавляет 5 усталости за ход, пока питомца
не вылечат. Лечение восстанавливает здоровье, снимает болезнь и расходует одну
дозу. После лечения также выполняется обычный ход, поэтому повторное заражение
возможно. Урон здоровью на ходе лечения компенсируется: доза на 20 HP даёт
видимый прирост 20 HP, пока не достигнут максимум 100. Остальные показатели
обновляются как обычно; на следующем ходе урон снова применяется полностью.
Купленные лекарства имеют отдельные счётчики использований.

При здоровье ровно 0 питомец ещё жив. Игра заканчивается, когда здоровье
становится отрицательным. Действия после смерти запрещены.

## Структура

- `game/clicker.py`: AbstractClicker и SimpleRandomClicker.
- `game/tamagochi.py`: AbstractTamagochi и SimpleTamagochi.
- `game/game.py`: AbstractGame и SimpleGame, покупки и инвентарь.
- `game/models.py`: Food и Medicine.
- `game/exceptions.py`: игровые исключения.
- `main.py`: консольное меню и точка входа.

Свойство питомца `status` возвращает словарь показателей; `get_status()` игры
добавляет монеты. Только игра вызывает `update()` после успешного действия,
поэтому один ход не обновляется дважды. Конкретные компоненты можно заменить
другими реализациями тех же интерфейсов.

## Разработка и проверки

Создайте окружение и установите инструменты:

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Активация в Linux/macOS:

```bash
source .venv/bin/activate
```

После активации:

```bash
python -m pip install -r requirements.txt
python -m ruff check ./game main.py
python -m flake8 ./game main.py
python -m pip check
```

Ruff и Flake8 нужны только для разработки.
